# AppTimeTracker · 软件时钟

简易中文 Windows x64 桌面计时器，记录软件窗口打开的时间。当前源码版本 1.1.3。本仓库包含核心源码、构建配置及使用说明。更新信息见 [CHANGELOG.md](CHANGELOG.md)。

## 直接使用

1. 按下方“从源码构建”生成发布目录，将整个目录放到长期保留的位置。自包含发布目录带有 .NET 10 运行环境，运行时无需安装 SDK 或 Python。
2. 双击 AppTimeTracker.exe。必须保留同目录的 DLL 和运行环境文件，不能只复制 EXE。
3. 将软件 EXE 拖入界面，自动登记并启动；也可“添加软件”后等待软件打开，或点击“启动”。
4. 关闭界面后在托盘继续监控；右键托盘选择“退出并保存”才停止。
5. 默认启用“登录 Windows 后自动启动到托盘”。这是当前用户登录后的自启动，未登录时不会运行；取消勾选即可关闭。重复运行会唤起已有界面。

移动程序目录前先退出，移动后运行新位置的 EXE 更新自启动路径。首次运行创建当前用户数据库及登录启动配置，不需要管理员权限。发布版未做代码签名。

从旧版升级时，先在旧版托盘菜单选择“退出并保存”，再打开新版 EXE；如果旧版仍在运行，重复启动只会唤起旧版界面。新版继续使用同一用户数据库，现有历史无需迁移。

同一 Windows 账号跨登录会话只允许运行一个实例，避免同时恢复和写入同一数据库。如果计时器已在另一个登录会话运行，请先在那里退出。升级前先退出旧版。

## 计时规则

- 按规范化 EXE 完整路径识别，不按同名进程猜测。
- 可见顶层窗口、最小化窗口计时；切换到其他软件不暂停。隐藏窗口、工具窗口不计。
- 其他虚拟桌面中的窗口继续计时；应用主动通过 DWM 隐藏的窗口不计时。
- 同一软件多个窗口或实例累计一次；不同软件可同时计时。最后一个窗口关闭结束会话。
- 锁屏、休眠暂停；恢复后继续。普通键鼠无操作不暂停。
- 锁定状态按真实 Windows 会话查询并持续校正，UAC 安全桌面不视为锁屏。取消关机或注销后继续监控，关闭界面仍进入托盘。
- 计时器启动时已经打开的软件从发现时开始计时，不追溯过去。
- 每秒检查一次，极短窗口可能漏过。单调时钟保证墙钟调整不会直接放大累计值；超过三秒且原因未知的采样间隔保守排除，暂停秒数标为未知。

启动器可在“编辑”中保留启动路径，把实际软件 EXE 完整路径逐行填入监控路径。路径失效显示提示；受保护进程无法读取路径时不退回按进程名匹配。不保证所有商店应用或特殊启动器都能识别。

停用或移出列表保留历史；重新添加同一启动路径可恢复已移出的软件。

普通路径与 Windows 扩展盘符、扩展 UNC 路径使用一致的匹配规则。编辑软件时如与另一条记录的启动路径冲突，会明确拒绝保存并保留原 ID；恢复旧记录请使用添加操作。

## 计时备注

每个软件的每次计时有一条独立备注，可留空。主页“计时备注”列标明本次或最近一次的备注；选中软件后点击“编辑备注…”即可填写或修改，双击备注单元格也可打开。计时进行中、暂停或结束后均可编辑，不改变自动计时规则。尚无计时记录时不可填写，开始新一次计时不会沿用上一次备注。

在“历史与导出”的“会话明细”中选中记录，点击“编辑备注…”或双击该行，可补写或修改更早的备注。备注支持中文及多行，点击“保存备注”后存入当前用户数据库；保存失败会保留编辑内容供重试。取消或关闭编辑窗口不会保存修改。

导出窗口每次打开都默认“所有软件”，显示当前日期范围内的记录，不继承主页选中项或上次的单软件筛选。CSV 跟随界面当前的视图、日期及软件筛选，包含全部符合条件的记录，不限于当前页。累计汇总仍包含全部历史，不受日期范围限制。

三种视图和 CSV 均新增“备注”列。会话明细逐条显示各次备注；每日及累计汇总只有在一行对应一次计时时显示该备注，涉及多次计时时留空，不合并或任选某一条备注。需要查看每次备注时请使用会话明细。

## 数据与 CSV

数据库位于 `%LocalAppData%\AppTimeTracker\usage.db`。配置、会话、有效区间存入 SQLite，累计从明细计算，界面包含未到周期保存点的增量。

每五秒及会话开始、恢复、结束时提交后台保存；暂停、退出和系统会话结束时等待后台任务并保存最新尾段，因此短至一秒的会话在正常结束时也会保存。首页已移除周期保存提示，保存机制未改变。写入失败保留待写记录并重试，请勿强制关闭。异常退出恢复到最后成功保存位置，不补计离线时间。正常情况下可能损失约五秒尾段，磁盘长期故障时可能更多。损坏数据库不会被空库覆盖。

后台只写入独立快照，采样仍每秒进行；保存失败会合并最新记录重试，不以旧快照覆盖新增时长。隐藏到托盘或最小化时跳过表格刷新，显示窗口后更新累计。

备份前从托盘退出，再复制整个数据目录。不要只复制运行中的 usage.db，待检查点数据可能位于 usage.db-wal。

“历史与导出”提供明细、每日、累计三种视图及 UTF-8 BOM CSV。明细和每日按软件和日期筛选；累计统计全部历史，隐藏日期筛选，仍可选择软件：

| 类型 | 字段 |
|---|---|
| 会话明细 | 会话/软件 ID、名称、启动/监控路径、计时类型、开始/结束时间、时区、有效时长、已确认暂停时长、总时长、状态、结束原因、异常恢复标记、备注 |
| 每日汇总 | 日期、软件 ID、名称、计时类型、当天有效时长、当天有活动的会话数、总时长、备注 |
| 累计汇总 | 软件 ID、名称、计时类型、首次/最近记录时间、会话数、总时长、备注 |

所有时长采用 HH:mm:ss，例如 01:02:03；小时可超过 24，例如 126:42:10。按累计秒数取整显示，数据库仍保留原有精度。时间戳含偏移，正确转义引号、逗号、换行；可能被 Excel 当作公式的文本添加保护前缀。进行中会话结束时间为空，未知暂停时长为空。

“总时长”统一指该软件自首次记录以来的全部有效累计，统计截至导出时刻，不包含暂停，也不受当前日期区间限制。明细和每日表中，同软件多行会重复这一总时长，不能把这一列再次相加；如只需要每软件一行，请导出累计汇总。停用、移出列表及当前尚在计时的会话均保留在历史统计中；同名不同软件 ID 分开计算。

会话筛选返回与范围重叠的完整会话，每日汇总仅含所选日期区间，因此截断日期范围时两者总数不一定相等。CSV 按需生成，Excel 打开导出文件不会阻塞数据库计时。

系统时间回拨时保留真实起止时间，结束时间可能早于开始时间；有效秒数仍由单调时钟累计。筛选包含有效区间涉及的日期，不因倒序时间丢记录，也不将回拨跨过的未知日期当作有效日期。

## 界面

界面采用固定浅色的珍珠白磨砂视觉、浅冰蓝选中态和圆角表面，不显示 3D 玻璃环。保留 Windows 原生键盘操作、文件/日期选择器和高对比回退。Windows 11 支持时请求系统标题栏 Acrylic；WinForms 白色正文会覆盖系统背景，正文不提供实时透视桌面。旧版 Windows 和关闭系统透明效果时仍可正常使用。

## 从源码构建

在 Windows 上安装 .NET 10 SDK，然后在仓库根目录运行：

```powershell
dotnet restore AppTimeTracker/AppTimeTracker.csproj --configfile NuGet.Config
dotnet build AppTimeTracker/AppTimeTracker.csproj -c Release --no-restore
dotnet run --project AppTimeTracker/AppTimeTracker.csproj -c Release --no-build
```

生成 Windows x64 自包含发布目录：

```powershell
dotnet publish AppTimeTracker/AppTimeTracker.csproj -c Release -r win-x64 --self-contained true -o artifacts/AppTimeTracker-1.1.3
```

生成的 EXE、DLL 和运行环境文件需要一起分发。旧版 PowerShell/BAT 脚本、开发过程记录、SDK 缓存和发布产物不包含在本仓库中。

Linux 可使用 .NET 10 SDK 交叉构建和发布，在上述 restore、build、publish 命令中添加 `-p:EnableWindowsTargeting=true`。窗口、托盘及 Windows 会话监控仍需在 Windows 运行验证。

核心回归测试可在 Linux 或 Windows 运行：

```sh
dotnet restore tests/AppTimeTracker.Regression/AppTimeTracker.Regression.csproj --configfile NuGet.Config
dotnet run --project tests/AppTimeTracker.Regression/AppTimeTracker.Regression.csproj -c Release --no-restore
```

测试说明及范围见 [核心回归测试](tests/AppTimeTracker.Regression/README.md)。
